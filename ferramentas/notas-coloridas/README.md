# Notas Coloridas (ferramenta separada)

Arquivo único (`index.html`), sem login e sem servidor: toque uma nota no
teclado e ela aparece na tela como uma bolinha colorida (Dó vermelho, Sol
azul…). É a mesma tela da aba "Notas" do app, mas independente dele.

Entradas: teclado MIDI (Chrome/Edge), microfone ou teclado na tela. No
computador, as teclas A S D F G H J tocam Dó a Si.

## Como usar

- Dê dois cliques no `index.html` (abre no navegador), ou
- publique a pasta com GitHub Pages / Vercel / Netlify. O microfone e o MIDI
  exigem endereço `https://` (ou `localhost`); abrir o arquivo direto do
  disco pode bloquear o microfone em alguns navegadores.
